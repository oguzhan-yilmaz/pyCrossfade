# pyCrossfade examples

Recipes for the v0.4.0 crossfade options — CLI flags and Python SDK settings.

| Guide | What it covers |
|-------|----------------|
| [cli.md](./cli.md) | `pycrossfade crossfade` and `crossfade-many` with every tunable flag |
| [sdk.py](./sdk.py) | `CrossfadeSettings`, fade/EQ profiles, gains, and inspecting `Transition` results |

Paths below assume Docker with `audios/` mounted at `/app/audios` (see the main [README](../README.md#cli)). Replace `master.mp3` / `slave.mp3` with your files.
